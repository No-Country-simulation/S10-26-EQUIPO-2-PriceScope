# Backend

Scaffold inicial del backend con Express y TimescaleDB.

## Scripts

```bash
npm run dev   # Desarrollo
npm run lint  # Linter
npm start     # Producción local
```

## Base de datos local (TimescaleDB)

```bash
docker compose up -d
```

La base `pricescope` se levanta vacía con la extensión de TimescaleDB habilitada.
